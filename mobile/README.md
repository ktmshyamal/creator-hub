# Creator Hub for Android

On GitHub: **Actions**, **Build Android APK**, **Run workflow**. After about 6 minutes download
**Creator-Hub-Android-APK**, unzip, copy `app-debug.apk` to the phone, open it and allow
"Install unknown apps" for your file manager or browser.

PDFs and backups open the phone's Share sheet so you can save them to Files or send them on WhatsApp.
The PDF library is bundled, so quotes and invoices work offline.
